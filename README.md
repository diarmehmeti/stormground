# Stormground (full package)

- `server/`      the game server. Start it with `node server.js` (see server/README.md).
- `android-app/` the Android app wrapper (Capacitor) with Google Play purchases and AdMob videos.
- `docs/`        **LISTING.md = the step-by-step guide to publish on Google Play**, plus the store images.

Start with `docs/LISTING.md`.
